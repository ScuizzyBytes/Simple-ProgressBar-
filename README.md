# ⚡ CYBER SYSTEM MONITOR v1.0

> A lightweight, real-time desktop hardware monitor built with Python, CustomTkinter, and `psutil`. Designed with a futuristic dark aesthetic and non-blocking multi-threaded architecture.

---

## 🛠️ Tech Stack & Features

- **Python 3.10+** — Core engine
- **CustomTkinter** — Modern dark-mode GUI
- **`psutil`** — System metrics extraction
- **`threading`** — Non-blocking UI updates via background worker threads

### 🚀 Key Capabilities
- 📊 **Real-time CPU Monitoring:** Instant visual tracking of processor load.
- ⚡ **Asynchronous Threading:** Dynamic metric polling without UI freezing or lag.
- 🪟 **Frameless & Transparent Aesthetic:** Sleek fixed geometry with semi-transparency support.
